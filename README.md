# Elevare Backend

Elevare is a goal tracking and productivity backend system built using Node.js, Express, and MongoDB.

## 🚀 Features Implemented

- User registration
- User login
- Password hashing using bcrypt
- JWT authentication (middleware prepared)
- Goal model setup
- Protected route structure

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Bcrypt

## 📂 Project Structure

server/
 ├── index.js
 ├── models/
 ├── middleware/
 ├── package.json

## ⚙️ Setup Instructions

1. Clone the repository
2. Run `npm install`
3. Create a `.env` file with:
   - MONGO_URI
   - JWT_SECRET
4. Run `npm run dev`
